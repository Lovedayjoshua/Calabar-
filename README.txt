CALABAR FRINGE 2026 — WEBSITE STARTER

Files:
- index.html: responsive one-page website with animated hero, festival theme, open call, and calls for vendors, volunteers, and attendees.

Preview:
Open index.html in a browser.

Deploy to Vercel:
1. Create a GitHub repository and upload index.html to the repository root.
2. Import that repository in Vercel, or use Vercel's static deployment flow.
3. No build command is required for this plain HTML starter.

Before publishing:
- Confirm event dates, official application deadline, email address, venue, and programme with the organisers.
- Replace the text-based festival mark with official logo artwork if you have permission to use it.
- The buttons currently open email drafts; they do not save submissions or provide an admin dashboard.
